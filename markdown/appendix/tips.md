# 常见提示

使用中常见的提示和处理办法如下。若遇到本说明未覆盖的提示，请记下单据编号和提示内容，联系系统管理员处理。

| 提示内容 | 出现场景 | 处理方法 |
| --- | --- | --- |
| 不满足限制提交条件：请填写… | 必填项未填写就提交 | 按提示补全字段后再提交 |
| 不满足限制提交条件：请先完成现勘定位打卡 | 勘察未定位就提交 | 先完成现勘定位打卡 |
| 限制提交：需先完成 电站派工 | 派工完成前提交领料 | 等派工审核通过后再提交 |
| 需先完成 工程领料 | 领料完成前提交支架或电气报装 | 先完成工程领料 |
| 没有该操作权限 | 角色无此功能，或设计单尚未接单 | 请改由具备该功能权限的角色办理，或先在电站设计列表接单 |
| 当前单据状态不允许该操作 | 对已完成或只读单据保存、修改 | 已完成、待审核、关闭的单据不能再改 |
| 抱歉，您访问的页面不存在 | 电脑端打开不属于本角色的页面 | 点「返回首页」 |
| 无可用审批人，单据仍可提交 | 当前审批节点在范围内找不到审批人 | 可以提交，但请管理员检查审批设置 |
| 审批已停用，自动通过 | 该单据的审批已被停用 | 新提交的单据直接完成，这是预期行为 |
| 已退回到待领料 | 对已完成的领料点退回 | 单据回到待领料，可以重新填写再提交 |
| 已派工 | 消缺工单手工派工成功 | 由被派执行人在工单详情中登记 |

## 使用提醒

- 审核中心的业务分类页签较长时，名称可能被截断，左右滑动即可看全。
- 建档或备货提交并进入待审核后，电站详情里仍可能暂时看到「办理」按钮，不必再次办理。
- 部分照片槽位在提交时不会逐项校验，请在提交前自行检查是否传齐。
- 列表筛选和搜索会真正拦住不符合条件的单据。
- 没有写权限时只能查看，不能保存或提交。
- 待提交等办理中状态为橙色，已完成为绿色，审核驳回为橙色。

# 角色与权限

权限分为两层：功能权限决定能看到哪些菜单、能做哪些操作；数据范围决定能看到哪些电站和单据。没有相应写权限时，打开单据只能看，不能保存、提交或改附件。

## 功能权限

现场端的应用入口按角色显示。打开没有权限的功能时，现场端会提示「没有该操作权限」；电脑端访问不属于本角色的页面时，会显示「抱歉，您访问的页面不存在」，点「返回首页」即可。

设计单在「待接单」状态时，尚未接单的人不能直接填写或提交，系统同样会提示没有操作权限。请先在电站设计列表中接单。

建设类单据（派工、领料、复核、支架、电气、电表）按有效派工明细划分可见范围：未派给本队的电站，现场负责人看不到；管理角色可以查看，但不代为填写或提交。只有安装队负责人（队长）才能新建派工批次和改派，普通队员不能建单或改派。

## 数据范围示例

以江苏电站为例：江苏开发经理和总部管理都能查到，浙江分公司经理查询同一电站时会显示「暂无数据」。换 `sales` 登录，也看不到不属于本人的江苏电站。转派后，原处理人的待办中不再出现该单，由接收人继续办理。

## 只读与可编辑

以下状态的单据为只读，不能改字段、上传或保存：待审核、审核中、已完成、关闭、已提交、作废。待提交、撤回待提交、待勘察、待签约、待设计、审核驳回等状态，在具有写权限时仍可编辑。

已完成的单据再点保存，系统会提示「当前单据状态不允许该操作」。

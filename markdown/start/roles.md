# 角色与权限

权限分为两层：功能权限决定能看到哪些菜单、能做哪些操作；数据范围决定能看到哪些电站和单据。没有相应写权限时，打开单据只能看，不能保存、提交或改附件。

## 角色一览

下表是各岗位的数据范围和主要工作。菜单和权限需由已授权的管理员在电脑端「系统管理 → 角色管理」中调整。

| 角色 | 数据范围 | 主要做什么 |
| --- | --- | --- |
| 开发经理 | 仅本人 | 新建业主、商机初勘、补贴、签约、备案 |
| 现勘员 | 本部门 | 勘察定位、拍照、提交；可转派、设优先级 |
| 设计师 | 本部门 | 在「待接单」中接单，进入「待设计」后填写并提交 |
| 项目经理 | 本部门及下级 | 办理电站建档 |
| 仓储/供应链 | 按授权范围 | 办理电站备货。界面上可能显示为「仓储专员」 |
| 安装队负责人 | 本队 | 批量派工、领料、复核、支架、电气、电表、安全打卡 |
| 审核员 | 按待办处理 | 在审核中心通过或驳回 |
| 分公司经理 | 本公司及下级 | 可查看范围内电站，也可作为审批人 |

审批设置、现场端品牌和角色菜单需由已授权的管理员在电脑端操作。还可以按业务需要增加自定义审批角色，不必局限于上表。

## 功能权限

现场端的应用入口按角色显示。打开没有权限的功能时，现场端会提示「没有该操作权限」；电脑端访问不属于本角色的页面时，会显示「抱歉，您访问的页面不存在」，点「返回首页」即可。

设计单在「待接单」时，行内操作是「详情」「终止」「接单」，没有转派，也没有优先级。尚未接单时不能直接填写或提交，系统会提示没有操作权限。请先打开电站设计的「待接单」页签并点「接单」。接单后单据离开「待接单」，出现在「待设计」中，状态变为「待设计」，行内操作改为「详情」「编辑」「终止」。电脑端和现场端数据一致，刷新后即可看到相同结果。若刚刚获得新权限仍看不到「接单」，请退出登录后再登录。

建设类单据（派工、领料、复核、支架、电气、电表）按有效派工明细划分可见范围：未派给本队的电站，现场负责人看不到；管理角色可以查看，但不能代为填写或提交。只有安装队负责人（队长）才能新建派工批次和改派，普通队员不能建单或改派。

## 数据范围示例

以江苏电站为例：江苏开发经理和总部管理都能查到，浙江分公司经理查询同一电站时会显示「暂无数据」。仅本人数据范围的开发经理，也看不到不属于本人的江苏电站。转派后，原处理人的待办中不再出现该单，由接收人继续办理。

## 只读与可编辑

以下状态的单据为只读，不能改字段、上传或保存：待审核、审核中、已完成、关闭、已提交、作废。待提交、撤回待提交、待勘察、待签约、待设计、审核驳回等状态，在具有写权限时仍可编辑。

已完成的单据再点保存，系统会提示「当前单据状态不允许该操作」。

# 电站设计

## 这个模块干什么

电站签约审核通过后开启电站设计。设计师先接单，再填写设计方式、组件数量、装机容量，并上传施工图纸和 BOM 摘要，提交后进入审核。

## 谁来用

设计师在「电站设计」列表中接单并提交。设计单生成后不会出现在工单中心的待办里，必须从本列表进入。

## 从哪里进入

- 现场端：「应用」→「电站开发」→「电站设计」。
- 电脑端：首页或「开发/交付」中的「电站设计」。

## 操作步骤

1. 打开「待接单」页签，找到对应设计单，点「接单」。未接单时直接填写或提交，系统会提示「没有该操作权限」。
2. 接单后状态变为「待设计」，按钮改为「详情」「编辑」「终止」。
3. 填写设计信息。必填通常包括：设计方式、组件数量、装机容量、施工图纸 DWG 和施工图纸 PDF。设计方式选项包含「第三方设计」，以及标准设计、定制设计。
4. 按需要填写并网接入点距离、设计备注、容配比、支架图、组串图、一次接线图和设计 BOM。
5. 确认无误后提交。

「项目公司」「产品」等字段请按页面选择或填写，不要把它理解成系统已经自动匹配完成。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待接单 | 详情、终止、接单。没有转派，也没有优先级 |
| 待设计、审核驳回 | 详情、编辑、终止 |
| 待审核 | 详情 |
| 已完成、关闭 | 详情 |

列表中还可能出现「财务审核」页签。演示环境默认通常只有一个审批节点；若业务需要增加复核，请管理员在审批设置中追加节点，而不必查找名为「财务审核」的固定状态。

没有写权限时只能查看。

## 提交之后会发生什么

审批启用时进入待审核。电站设计与备案登记都通过后，开启 [电站建档](/design/archive.html)。

## 注意事项

计算排布、自动出图尚未开放。请上传已准备好的图纸和排布资料。

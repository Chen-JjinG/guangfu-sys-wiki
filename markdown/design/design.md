# 电站设计

## 这个模块干什么

电站签约审核通过后开启电站设计。设计师先在列表中接单，再填写设计方式、组件数量、装机容量，并上传施工图纸和 BOM 摘要，提交后进入审核。

## 谁来用

设计师在「电站设计」列表中接单并提交。设计单生成后不会出现在工单中心的待办里，必须从本列表进入。电脑端和现场端看到的是同一批设计单，操作方式相同。

## 从哪里进入

- 现场端：「应用」→「电站开发」→「电站设计」。
- 电脑端：首页或「开发/交付」中的「电站设计」。

## 操作步骤

1. 打开「待接单」页签，找到对应设计单。待接单状态下，行内操作是「详情」「终止」「接单」，没有「转派」，也没有「优先级」。
2. 点「接单」。接单后，这张单会离开「待接单」，出现在「待设计」页签下，状态变为「待设计」。行内操作改为「详情」「编辑」「终止」，不再显示「接单」。
3. 电脑端和现场端用的是同一套数据。在一端接单后，到另一端刷新列表，单据、状态和数量都会一致。
4. 接单之后再填写设计信息。未接单时直接填写或提交，系统会提示「没有该操作权限」。必填通常包括：设计方式、组件数量、装机容量、施工图纸 DWG 和施工图纸 PDF。设计方式可选「第三方设计」「标准设计」「定制设计」。
5. 按需要填写并网接入点距离、设计备注、容配比、支架图、组串图、一次接线图和设计 BOM。
6. 确认无误后提交。

「项目公司」「产品」等字段请按页面选择或填写，不要以为系统已经自动匹配完成。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待接单 | 详情、终止、接单。没有转派，也没有优先级 |
| 待设计、审核驳回 | 详情、编辑、终止 |
| 待审核 | 详情 |
| 已完成、关闭 | 详情 |

列表中还可能出现「财务审核」页签。演示环境默认只有一个审批节点。若需要增加复核，请管理员在审批设置中追加节点；系统中并不存在名为「财务审核」的固定状态。

没有写权限时只能查看。

## 提交之后会发生什么

审批启用时进入待审核。电站设计与备案登记都通过后，开启 [电站建档](/design/archive.html)。

## 注意事项

- 计算排布、自动出图尚未开放。请上传已准备好的图纸和排布资料。
- 若刚刚获得设计师相关权限，列表里还看不到「接单」，请先退出登录，再重新登录后查看。

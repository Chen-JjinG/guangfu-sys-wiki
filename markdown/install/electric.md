# 电气报装

## 这个模块干什么

施工复核通过后开启电气报装。安装队完成电气安装定位，手工登记设备序列号，上传安装取证，并按需要上传完工自检 PDF，然后提交。

## 谁来用

被派到该电站的安装队负责人。审核员负责通过或驳回。

## 从哪里进入

- 现场端：「应用」→「电站建设」→「电气报装」。
- 电脑端：首页或建设菜单中的「电气报装」。

## 操作步骤

1. 打开「待报装」单据。领料未完成时不能提交。
2. 完成电气安装定位。
3. 在设备登记中手工填写组件 SN（一行一块）、逆变器 SN、采集器 SN 和并网箱 SN。系统不支持拍照识别，当前也不把扫码录入作为正式操作步骤。
4. 上传逆变器整体照片、逆变器铭牌、外壳接地等必填照片，其他取证按需上传。
5. 如需提交完工自检，请直接上传「竣工自检报告 PDF」。系统不会在页面里生成报告，详见 [完工自检](/install/selfcheck.html)。
6. 确认后提交。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待报装、审核驳回 | 详情、编辑。待报装没有终止按钮 |
| 待审核 | 详情 |
| 已完成、关闭 | 详情 |

页签和角标都使用「待报装」。没有写权限时只能查看。

## 提交之后会发生什么

审批启用时进入待审核。电气与支架都通过后，开启电表安装。

## 注意事项

请核对 SN 是否与实物一致。「清空设备」、自动识别等能力尚未开放。

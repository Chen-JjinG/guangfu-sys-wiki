# 总体说明

**国华光伏建设管理系统** 用于办理户用分布式光伏项目：从登记业主、商机初勘、现场勘察、补贴与签约、备案和设计，到建档、备货、派工、领料、施工复核、支架和电气报装，再到电表安装。电脑端和现场端共用同一套账号和数据。

这份说明面向实际使用的同事和前来演示的客户，按当前演示环境可以完成的操作编写。左侧目录可以展开或收起，右上角可以搜索，每一页右侧是本页目录。

## 系统是干什么的

系统把一条电站从线索做到装表的过程拆成一张张业务单据。每一张单都有自己的状态、办理人和审核节点。上一环节完成后，系统会按「开启条件」打开下一张单；有的环节还有「限制提交」，例如领料必须等派工完成才能提交。

它不替代供电公司或电网侧的正式并网手续，也不在这一期提供电站发电监控、质量整改整单、变更对照、电子签署或证件自动识别。这些未开放能力见 [当前未开放的能力](/appendix/not-open.html)。

## 主流程走哪几步

建议按职责换账号走一遍，不要用同一个管理员账号包办所有单据。

1. 开发经理新建 [业主](/owner/owner.html)，再提交 [商机初勘](/owner/opportunity.html)。
2. 审核员在 [审核中心](/audit/audit.html) 通过后，现勘员办理 [电站勘察](/survey/survey.html)。
3. 勘察通过后，[业主补贴](/survey/subsidy.html) 与 [合同签约](/survey/contract.html) 同时开启，由开发经理办理。
4. 补贴通过后开启 [备案登记](/survey/filing.html)；签约通过后开启 [电站设计](/design/design.html)。设计师需要先接单再提交。
5. 备案和设计都通过后，项目经理办理 [电站建档](/design/archive.html)。
6. 建档通过后，[电站备货](/design/stock.html) 与 [安装队派工](/install/dispatch.html) 同时开启。仓储办理备货，安装队负责人新建派工批次。
7. 备货通过后开启 [工程领料](/install/pick.html)，但要等派工完成才能提交。派工通过后开启 [施工复核](/install/review.html)。
8. 复核通过且领料完成后，提交 [支架报装](/install/bracket.html) 和 [电气报装](/install/electric.html)。[完工自检](/install/selfcheck.html) 在电气报装里以 PDF 上传完成。
9. 支架和电气都完成后，开启 [电表安装](/install/meter.html)。

[产权证明](/property/property.html) 和 [消缺工单](/property/defect.html) 是电站开发中的独立模块，不作为上述主路径的必经闸门。安全打卡跟随已派工的电站，不卡住领料或报装。更完整的示意图见 [快速上手](/start/quick-start.html)。

## 常见角色分工

| 角色 | 典型账号 | 主要工作 |
| --- | --- | --- |
| 开发经理 | `sales`、`salesjs` | 业主、初勘、补贴、签约、备案 |
| 现勘员 | `surveyor`、`surveyor2` | 勘察定位、拍照、转派 |
| 设计师 | `designer` | 电站设计接单与提交 |
| 项目经理 | `pm01` | 电站建档 |
| 仓储 | `stock` | 电站备货 |
| 安装队负责人 | `crew`、`crew2`、`crew3` | 派工、领料、复核、报装、电表、安全打卡 |
| 审核员 | `auditor` | 审核中心通过或驳回 |
| 分公司经理 / 总部管理 | `manager`、`hqadmin` | 查看范围内电站，也可作为审批人 |
| 系统管理员 | `admin` | 审批设置、现场端品牌、角色菜单；不作为默认的建档或备货办理人 |

没有写权限时只能查看，不能保存或提交。数据范围不同，能看到的电站也不同，详见 [角色与权限](/start/roles.html)。

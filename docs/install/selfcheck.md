# 完工自检

## 这个模块干什么

完工自检用来归档竣工自检报告。当前只支持在电气报装表单中 **上传 PDF**，系统不会在页面里生成报告，也没有单独的填写或签字页。

## 谁来用

办理电气报装的安装队负责人。

## 从哪里进入

没有单独的「完工自检」应用宫格。请打开 [电气报装](/install/electric.html) 单据，在表单中找到「竣工自检报告 PDF」。

## 操作步骤

1. 在电脑或其他设备上准备好自检 PDF。
2. 打开对应电站的电气报装表单。
3. 在「竣工自检报告 PDF」处上传文件。页面提示为：上传自检 PDF，不在页面里生成报告。
4. 与电气报装的其他必填项一并保存或提交。

## 状态与按钮

完工自检本身没有独立的状态页签，它随电气报装单据走。电气报装在待报装、审核驳回时可以编辑并更换附件；进入待审核或已完成后只读。

## 提交之后会发生什么

PDF 作为电气报装资料一起进入审核。通过后随电气报装归档，不会另外生成一份系统报告。

## 注意事项

请不要等待系统自动出报告或打开签字板。若还没有 PDF，请先在线下完成自检再上传。

# 工程领料

## 这个模块干什么

电站备货审核通过后开启工程领料。安装队按派工明细领取物料并提交审核。领料还要等派工完成才能提交；领料完成后，支架报装和电气报装才允许提交。

## 谁来用

被派到该电站的安装队负责人（如 `crew`）。没有写权限或未被派到的人只能看或看不到该单。

## 从哪里进入

- 现场端：「应用」→「电站建设」→「工程领料」。
- 电脑端：首页或建设菜单中的「工程领料」。

## 操作步骤

1. 打开「待领料」单据。表单会带出派工明细信息，例如安装队、派单人、计划施工和完工日期。
2. 填写领料明细：物料名称、数量、单位、出库仓库为必填，备注为选填。
3. 若派工尚未完成，电脑端和现场端都会提示「限制提交：需先完成 电站派工」，提交按钮不可用。请等派工审核通过后再提交。
4. 派工完成后，检查明细并提交。

已完成的领料单可以点「退回」。退回后状态回到「待领料」，单据保留，并写入操作日志，可以重新填写再提交。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待领料、审核驳回 | 详情、编辑、终止 |
| 待审核 | 详情 |
| 已完成 | 详情、退回 |
| 关闭 | 详情 |

没有写权限时只能查看。筛选会真正拦住列表。

## 提交之后会发生什么

审批启用时进入待审核。领料与施工复核都完成后，[支架报装](/install/bracket.html) 和 [电气报装](/install/electric.html) 才允许提交。

## 注意事项

退回是把已完成的领料退到待领料，不是删除单据，也不是退回到更早的派工环节。

# 支架报装

## 这个模块干什么

施工复核通过后开启支架报装。安装队完成安装基准定位，并上传立柱连接、支架结构和安全防护等取证照片后提交。支架和电气都完成后，开启电表安装。

## 谁来用

被派到该电站的安装队负责人。审核员负责通过或驳回。

## 从哪里进入

- 现场端：「应用」→「电站建设」→「支架报装」。
- 电脑端：首页或建设菜单中的「支架报装」。

## 操作步骤

1. 打开「待报装」单据。若领料尚未完成，页面会提示限制提交，需先完成工程领料。
2. 完成「安装基准定位」。
3. 上传必填取证：配重照片，立柱与基础连接照片，支架结构图，人身防护照片，安全文明施工警示牌和安全警示牌。施工禁入警示牌等按页面要求选传。
4. 确认后提交。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待报装、审核驳回 | 详情、编辑。待报装没有终止按钮 |
| 待审核 | 详情 |
| 已完成、关闭 | 详情 |

页签和角标都使用「待报装」，三者用词一致。没有写权限时只能查看。

## 提交之后会发生什么

审批启用时进入待审核。支架与电气都通过后，开启 [电表安装](/install/meter.html)。

## 注意事项

配重、立柱连接和人身防护等照片请拍摄清楚，读数和防护装备要能看清。演示辅助按钮不能代替现场取证。

# 施工复核

## 这个模块干什么

安装队派工审核通过后开启施工复核。施工前在现场核对房屋和遮挡等条件，登记是否存在新增遮挡、裂缝漏水、墙体或木檩条问题，并上传证据后提交。

## 谁来用

被派到该电站的安装队负责人。审核员负责通过或驳回。

## 从哪里进入

- 现场端：「应用」→「电站建设」→「施工复核」。
- 电脑端：首页或建设菜单中的「施工复核」。

## 操作步骤

1. 打开「待登记」的复核单。
2. 按页面逐项回答必填问题：现场是否存在新增遮挡物或遮挡隐患，待安装房屋是否存在裂缝或漏水，是否存在土坯墙、干砌墙、泥浆或石灰砌墙，是否存在木檩条腐烂、虫蛀、变形、开裂。
3. 按需要填写备注、建议解决方案，并上传证据照片。
4. 确认后提交。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待登记、审核驳回 | 详情、编辑、终止 |
| 待审核 | 详情 |
| 已完成、关闭 | 详情 |

没有写权限时只能查看。

## 提交之后会发生什么

审批启用时进入待审核。复核通过后开启支架报装和电气报装；这两项还要等领料完成后才能提交。

## 注意事项

复核结果关系到能否安全施工。若现场条件不合格，请如实登记并上传证据，不要为了提交而填写不实选项。

# 备案登记

## 这个模块干什么

在一次性租金补贴审核通过后，登记备案交流侧容量、备案证项目代码、电网审核资料，并上传备案证明和电力接入函，提交后进入审核。备案和电站设计都通过后，才开启电站建档。

## 谁来用

开发经理（如 `sales`）办理。电脑端和现场端都可以办理。审核员负责通过或驳回。

## 从哪里进入

- 现场端：「应用」→「电站开发」→「备案登记」。
- 电脑端：首页或「开发/交付」中的「备案登记」。

## 操作步骤

1. 打开「待处理」的备案单。补贴尚未通过时，本环节不会开启。
2. 填写必填项：备案交流侧容量（kW）、备案证项目代码、电网审核资料类型，并上传备案证明和电力接入函。下拉项未选择就提交会被拦住。
3. 确认无误后提交。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待处理、撤回待提交、审核驳回 | 详情、编辑、终止 |
| 待审核 | 详情 |
| 已完成、关闭 | 详情 |

没有写权限时只能查看。筛选会真正拦住列表。

## 提交之后会发生什么

审批启用时进入待审核。备案与电站设计都审核通过后，系统开启 [电站建档](/design/archive.html)。只完成其中一项，建档还不会打开。

## 注意事项

请按电网或备案机关的实际资料上传，不要用演示图片代替正式证明。

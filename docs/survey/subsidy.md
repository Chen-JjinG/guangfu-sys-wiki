# 业主补贴

## 这个模块干什么

登记一次性租金补贴的单价、确认依据和证明材料，提交后进入审核。补贴审核通过后，开启备案登记。

## 谁来用

开发经理（如 `sales`）办理。待确认状态下可以把单据转派给其他有权限的人。审核员负责通过或驳回。

## 从哪里进入

- 现场端：「应用」→「电站开发」→「业主补贴」。
- 电脑端：首页或「开发/交付」中的「业主补贴」。电脑端和现场端都可以办理。

电站勘察审核通过后，补贴与签约同时开启，可以并行办理。

## 操作步骤

1. 打开「待确认」的补贴单。
2. 填写「一次性租金补贴单价（元/单块）」，并上传确认依据和证明材料。单价未填写就提交，系统会提示「不满足限制提交条件：请填写一次性租金补贴单价(元/单块)」。
3. 确认无误后提交。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待确认 | 详情、编辑、终止、转派。待确认没有优先级按钮 |
| 待审核 | 详情 |
| 审核驳回 | 详情、编辑、终止 |
| 已完成、关闭 | 只保留详情 |

没有写权限时只能查看。筛选会真正拦住列表。待提交或待确认类状态为橙色，已完成为绿色，审核驳回为橙色。

## 提交之后会发生什么

审批启用时进入待审核，审核通过后变为已完成，并开启 [备案登记](/survey/filing.html)。若管理员为补贴配置了多个审批节点，通过一个节点后会进入下一节点，直到最后一节点通过。

## 注意事项

证明材料请按实际业务上传。演示环境如允许用截图代替视频，只适用于演示，正式办理请按页面要求准备资料。

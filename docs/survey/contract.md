# 合同签约

## 这个模块干什么

登记电站签约信息，包括房产与地址、收益分享账号和合同内容，提交后进入审核。签约审核通过后，开启电站设计。

## 谁来用

开发经理（如 `sales`）办理。审核员负责通过或驳回。

## 从哪里进入

- 现场端：「应用」→「电站开发」→「电站签约」。
- 电脑端：首页或「开发/交付」中的「电站签约」。

勘察通过后，签约与补贴同时开启，可以并行办理。

## 操作步骤

1. 打开「待签约」单据。
2. 填写房产证类型、乡镇、详细地址等必填地址信息。
3. 填写收益分享账号：银行卡号、开户行、持卡人名称、持卡人手机号，并上传银行卡照片。选择开户行后，开户行号会带出并只读显示，不必手填行号。
4. 填写合同信息，例如租金结算模式、租金单价、合同编号和附件。签署方式请按纸质合同登记，可选择「纸质签署」。
5. 确认无误后提交。

## 状态与按钮

| 状态 | 常见按钮 |
| --- | --- |
| 待签约、撤回待提交、审核驳回 | 详情、编辑、终止 |
| 待审核 | 详情 |
| 已完成、关闭 | 详情 |

列表中还可能出现签署中、补充中、付款中、风控中等页签。当前主流程一般按待签约、待审核、已完成、审核驳回和关闭使用。没有写权限时只能查看。

## 提交之后会发生什么

审批启用时进入待审核；通过后单据变为已完成，系统开启 [电站设计](/design/design.html)。

## 注意事项

电子签署尚未作为正式能力开通。即使页面上可以看到「电子签署登记」一类选项，也请按纸质合同登记，不要把它理解成已经对接了在线签署。

电表安装

这个模块干什么

支架报装和电气报装都完成后，开启电表安装。安装队登记电表序列号、并网线缆长度，并上传装表取证后提交。

谁来用

被派到该电站的安装队负责人。未派给本队的电表单，现场负责人看不到。审核员负责通过或驳回。

从哪里进入

  • 现场端：「应用」→「并网闭环」→「电表安装」。
  • 电脑端：若菜单中有「并网电表安装」或「电表安装」，从该入口进入。电脑端首页宫格以当前环境实际显示为准。

图：现场端电表安装「待安装」单据只有「详情」和「编辑」。图中地址为演示数据，请按实际业务填写。

操作步骤

  1. 打开「待安装」单据。
  2. 填写电表序列号、实际并网线缆长度（米），备注为选填。
  3. 上传电表安装整体照片、电表箱整体照片、并网线缆规格照片。
  4. 确认后提交。

当前开放的是上述装表登记，并不包括多段视频或完整的并网登记资料。

状态与按钮

状态常见按钮
待安装、审核驳回详情、编辑。待安装没有终止、也没有派工按钮
待审核详情
已完成、关闭详情

页签和角标的名称均为「待安装」，而不是「待装表」。没有写权限时只能查看。筛选会实际生效，只显示符合条件的单据。

提交之后会发生什么

审批启用时进入待审核，通过后变为已完成。完整的并网登记资料办理尚未作为正式环节开放，见 当前未开放的能力。

注意事项
